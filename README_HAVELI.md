# Haveli Indian Kitchen Website

I have created a visually appealing Single Page Application (SPA) for **Haveli Indian Kitchen**.

## Features Implemented
- **Premium Design**: Dark theme with gold and deep red accents, using 'Outfit' and 'Playfair Display' fonts for a luxurious feel.
- **3D Effects**: Integrated `react-three/fiber` with a subtle floating sparkles and stars background that persists across the site.
- **Scroll Animations**: Used `framer-motion` to animate elements as they enter the viewport (fade-ins, slide-ups).
- **Responsive Layout**: Fully responsive design for mobile, tablet, and desktop.
- **Sections**:
  - **Hero**: Impactful landing with large typography and a call to action.
  - **Menu Highlights**: A grid showcasing signature dishes with high-quality generated images.
  - **Our Story**: An elegant section describing the restaurant's heritage.
  - **Footer**: Location, hours, and direct links to order on UberEats and DoorDash.

## Tech Stack
- **React** (Vite)
- **Three.js / React Three Fiber / Drei** (3D Background)
- **Framer Motion** (Animations)
- **CSS Modules** (Styling)
- **Lucide React** (Icons)
